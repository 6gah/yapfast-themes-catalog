# yapfast themes

the launch themes for [Yapfast](https://github.com/yapfast/yapfast) and the catalog the marketplace reads.

`themes/<name>/` holds each theme. `catalog.json` lists every theme at a pinned commit with the sha256 of its files, so what installs is what was listed.

to get a theme listed, open a pull request that adds your entry to `catalog.json`. see `docs/themes.md` in the yapfast repo.
